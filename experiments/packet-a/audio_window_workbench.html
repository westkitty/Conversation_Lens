Audio Window Workbench.

Edit actual recorded PCM sample boundaries. Keep/Drop windows without fabricating transcript results. This is an isolated integration harness, not the current Conversation Lens UI.

01 / Capture source

Load a deterministic 8-second source or use a browser microphone on localhost. A microphone requires a real device or browser fake-input flags; nothing is sent to a server in this harness.

No audio buffered. Start with the synthetic fixture to test exact edits.

02 / Sample-accurate edits

Select a window, then click or drag the cyan marker to choose an exact split point. Drag a boundary in the overview to adjust two neighboring windows together.

No cursor

Cyan line = split cursor. Waveform is from buffered PCM16 samples, not a decorative animation.

Drag a shared boundary between adjacent windows to move it without deleting or duplicating a single sample.

03 / Context and clip limits

Pre/post-roll adds samples from the surrounding ring without changing the primary window. Any padded or edited window forbids automatic speaker learning.
